# 📚 LearnTogether — Peer to Peer Learning App

A beautiful, fully functional peer-to-peer learning platform where users can browse, join, and host learning sessions on any topic.

## 🚀 Live Demo

Deploy instantly with **GitHub Pages** — no server needed!

## ✨ Features

- **Browse Sessions** — Search and filter learning sessions by topic, level, or keyword
- **Join Sessions** — Reserve a spot in any available session
- **Host a Session** — Create your own session and share your knowledge
- **Profile Page** — Track your skills, learning goals, and joined sessions
- **Persistent State** — All data saved to localStorage (no backend needed)
- **Responsive Design** — Works on desktop and mobile
